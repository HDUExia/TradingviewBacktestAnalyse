# MES 回放交易分析面板

基于你提供的 `@MES#C` 1 分钟历史数据，把 TradingView 回放交易记录解析成单笔交易，并用 Streamlit 构建交互式复盘面板。

---

## 启动方式

```bash
cd /Users/exia/git/ExiaQuant
source venv/bin/activate
streamlit run app.py
```

浏览器打开 `http://localhost:8501`（或终端提示的端口）。

---

## 功能

### 1. 汇总指标
- 总交易数
- 胜率
- 盈亏比
- 总盈亏
- 最大回撤
- 夏普比率
- 平均持仓时间

### 2. 交易详情
选择任意一笔交易，查看：
- 方向、进场/出场价、盈亏
- 进场/出场信号
- 最大浮盈（MFE）/ 最大浮亏（MAE）
- 持仓时长

### 3. 多周期 K 线同步
点击交易后，自动用 Qlib 加载该交易时间窗口的 K 线：
- **5 分钟**：精细看入场点
- **15 分钟**：看短期结构
- **60 分钟**：看背景趋势

图表上标注：
- 绿色/红色三角形：进场点
- 红色/绿色三角形：出场点
- 半透明背景：持仓区间（盈利为浅绿，亏损为浅红）

### 4. 范围控制
侧边栏滑块：
- 「进场前 K 线数」：向左扩展
- 「出场后 K 线数」：向右扩展

> Streamlit 不支持像 TradingView 桌面端那样直接拖拽加载更多数据，所以用滑块实现等效功能。

## 数据准备

### 已有数据
- `回放交易_CME_MINI_MES1!_2026-08-23_57da9.csv`：TradingView 回放交易记录

运行 `scripts/prepare_mes_intraday_qlib.py` 后生成：
- `data/qlib_data/futures_5min/`
- `data/qlib_data/futures_15min/`
- `data/qlib_data/futures_60min/`

---

## 数据匹配说明

如果你的交易记录价格与 Qlib 加载的历史 K 线不完全一致，可能原因：
1. 数据来源不同（回放数据 vs 导出数据）
2. 合约连续调整方式不同
3. 时区或夏令时处理差异

面板会在检测到价格不匹配时弹出黄色警告，但仍会按时间渲染 K 线上下文。
